# RiftRank v9 - Multi Profile

Arkadaşlarla paylaşılabilen tek APK sürümü.

- Uygulama içinden OP.GG profil linki girilir ve kaydedilir.
- Linkten oyuncu adı/tag ve bölge gösterilir.
- Yalnız Solo/Duo rank, LP, W/L ve winrate okunur.
- Rank değişince tema ve amblem otomatik değişir.
- Gerçek rank amblemi yenileme sırasında cache'e alınır; widget ağ isteği yapmaz.
- Widget yeniden boyutlandırılabilir ve launcher-safe statik rank gradient kullanır.
- Yaklaşık 30 dakikada bir WorkManager yenilemesi + manuel yenileme.
- Profil değişince eski günlük LP baseline'ı sıfırlanır.

Build: JDK 17 / Gradle 8.9 / AGP 8.7.3 / compileSdk 35 / targetSdk 35 / minSdk 26.
